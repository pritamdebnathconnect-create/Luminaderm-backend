# LuminaDerm "Skin-Analyzer"
<br>
Author: Pritam Debnath
<p>LuminaDerm is an AI-powered skin condition analysis web application designed to analyze uploaded skin images and provide a predicted skin condition along with a confidence score. The project uses deep learning and computer vision to assist users in getting a quick preliminary assessment of common skin conditions.

«Note: LuminaDerm is an educational/research project and is not intended to replace professional medical diagnosis.» </p>
